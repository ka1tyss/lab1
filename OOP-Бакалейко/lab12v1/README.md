Лабораторна робота No7

• Тема: Узагальнені типи (Generics). IRepository з where-обмеженнями та тестами.
• Тривалість: 80 хв (2 академічні години)
• Інструмент: .NET SDK, IDE (Visual Studio / VS Code), xUnit

Мета

Навчитися створювати узагальнені інтерфейси та класи, застосовувати where-обмеження
для типів-параметрів, а також розробляти юніт-тести для перевірки коректності узагальнених
реалізацій.
У межах лабораторної роботи №7 було успішно реалізовано узагальнений інтерфейс IRepository<T> із where-обмеженнями (where T : IEntity), створено клас сутності Product (Варіант 1) та розроблено надійну реалізацію репозиторію в пам'яті (InMemoryRepository<T>). Для перевірки коректності всіх CRUD-операцій та обробки виняткових ситуацій написано пакет юніт-тестів за допомогою фреймворку xUnit, які успішно пройшли перевірку в середовищі розробки та були завантажені до віддаленого репозиторію на GitHub.
