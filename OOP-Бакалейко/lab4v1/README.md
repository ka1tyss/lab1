Лабораторна робота No4
• Тема: Наслідування. Ключові слова base, override, virtual. Приховування членів (new).
• Тривалість: 80 хв (2 академічні години)
• Інструмент: .NET SDK, IDE на вибір студента

Мета
Навчитися створювати ієрархії класів, використовувати ключові слова base, virtual, override
для реалізації поліморфізму, а також розуміти відмінності між override та приховуванням членів
за допомогою new.
На практиці реалізовано ієрархію класів Employee rightarrow Manager rightarrow Director, де за допомогою ключового слова base забезпечено виклик конструкторів базового класу, а завдяки модифікаторам virtual та override досягнуто поліморфної поведінки при виклику методів через посилання базового типу.Також було досліджено різницю між перевизначенням (override) та приховуванням методів (new): перевизначений метод залежить від фактичного типу об'єкта в пам'яті, тоді як прихований метод залежить від типу змінної-посилання, через яку здійснюється виклик.
