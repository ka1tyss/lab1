Самостійна робота No2

• Тема: Перевантаження конструкторів: приклади та сценарії.
• Обсяг: 80 хв (2 академічні години)

Мета
Закріпити навички використання перевантажених конструкторів для створення гнучких та зручних
у використанні класів.

Під час виконання самостійної роботи №2 було закріплено навички перевантаження конструкторів у C#. На прикладі класу Product продемонстровано використання основного конструктора, делегування викликів за допомогою синтаксису : this(...) для швидкого створення об'єктів із базовими значеннями, а також реалізацію конструктора копіювання. Окрім того, було закріплено принципи інкапсуляції через використання read-only властивостей та перевизначення методу ToString() для зручного форматування виводу даних.ї
