Лабораторна робота №2 • Тема: Клас із кількома конструкторами. Життєвий цикл об’єкта.

Мета: Ознайомитися з перевантаженням конструкторів та їхнім ланцюговим викликом, вивчити життєвий цикл об’єкта, реалізувати деструктор та дослідити роботу збирача сміття (Garbage Collector).

Теоретичні відомості

Перевантаження конструкторів — можливість оголошувати кілька конструкторів із різним набором параметрів для гнучкості ініціалізації об’єктів.

Ланцюговий виклик (: this) — механізм, що дозволяє одному конструкторові викликати інший у межах того ж класу, уникаючи дублювання коду.

Життєвий цикл об’єкта — процес, що включає створення об'єкта (оператор new у купі), його використання через посилання та знищення збирачем сміття (GC), коли посилань більше не залишається.

Збирач сміття (Garbage Collector) та деструктор (~ClassName()) — система автоматичного керування пам'яттю, яка викликає деструктор перед звільненням ресурсів об'єкта.

Хід роботи: У ході виконання лабораторної роботи було реалізовано клас Book із приватним полем, властивостями та валідацією року випуску, перевантаженими конструкторами із ланцюговим викликом (: this), методом GetFullInfo() та деструктором. Для демонстрації життєвого циклу об’єктів їхнє створення було винесено в окремий метод, після чого за допомогою примусового виклику GC.Collect() та GC.WaitForPendingFinalizers() підтверджено автоматичне видалення екземплярів із пам'яті.
