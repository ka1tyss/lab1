Лабораторна робота No13

• Тема: Власні винятки та патерн Result.
• Тривалість: 80 хв (2 академічні години)
• Інструмент: .NET SDK, IDE на вибір студента

Мета

Навчитися створювати власні типи винятків для специфічних помилок, а також реалізовувати
патерн Result для більш контрольованої обробки помилок без використання винятків у
“нормальних” сценаріях невдачі.

У першому варіанті Result<T> доцільно використовувати для очікуваних сценаріїв невдачі або валідації вхідних даних, як-от некоректна сума поповнення (amount <= 0) у методі Deposit чи перевірка доступності коштів, оскільки це дозволяє коректно обробити відмову без накладних витрат на генерацію винятків. Натомість винятки — зокрема InsufficientFundsException із даними про запитану суму та поточний баланс — варто застосовувати у методі Withdraw для виняткових або критичних ситуацій, коли операцію неможливо завершити за поточним станом рахунку і потрібно перервати нормальний хід виконання з чіткою діагностикою причини.
