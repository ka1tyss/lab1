Лабораторна робота No6

• Тема: Наслідування. Ключові слова base, override, virtual. Приховування членів (new).

• Тривалість: 2 год

• Інструмент: .NET SDK, IDE на вибір студента

Мета

Навчитися створювати ієрархії класів, використовувати ключові слова base, virtual, override
для реалізації поліморфізму, а також розуміти відмінності між override та приховуванням членів
за допомогою new.

Висновки щодо виконання роботи
Під час виконання лабораторної роботи було створено ієрархію класів Employee → Manager → Director. За допомогою модифікаторів virtual та override було реалізовано поліморфізм (коректний виклик перезначених методів через посилання базового класу Employee).
