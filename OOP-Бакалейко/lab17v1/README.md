• Тема: LINQ: SelectMany, пагінація й custom extensions.
• Тривалість: 80 хв (2 академічні години)
• Інструмент: .NET SDK, IDE (Visual Studio / VS Code / Rider), Git

Мета

Навчитися використовувати оператор SelectMany для роботи з вкладеними колекціями,
реалізовувати пагінацію даних за допомогою LINQ, а також створювати власні методи
розширення для IEnumerable<T> або ключових доменних сутностей.

1. Оператор SelectMany та його відмінність від Select
Оператор SelectMany використовується для перетворення елементів колекції у вкладені послідовності з подальшим їх «розгортанням» (flattening) в один спільний плаский список. На відміну від звичайного Select, який працює за принципом «один до одного» і для вкладених списків поверне колекцію колекцій (наприклад, authors.Select(a => a.Books) дасть IEnumerable<List<Book>>), SelectMany об'єднує всі елементи в одну суцільну вибірку (authors.SelectMany(a => a.Books) поверне просто IEnumerable<Book>).

2. Пагінація даних за допомогою LINQ
Пагінація (посторінкове виведення даних) у LINQ реалізується комбінацією двох методів: Skip(), який пропускає задану кількість елементів від початку колекції, та Take(), який вибирає потрібну кількість наступних елементів для поточної сторінки. Стандартна формула для отримання конкретної сторінки виглядає як collection.Skip((pageNumber - 1) * pageSize).Take(pageSize), де pageNumber — номер сторінки (починаючи з 1), а pageSize — кількість записів на одній сторінці.

3. Концепція методів розширення та їх інтеграція з LINQ
Методи розширення (Extension Methods) дозволяють додавати нову функціональність до вже існуючих типів без зміни їхнього вихідного коду чи наслідування, оголошуючи статичний метод у статичному класі з модифікатором this перед першим параметром. Уся бібліотека LINQ побудована саме на цій концепції: стандартні оператори (Where, Select, Skip, Sum тощо) є методами розширення для інтерфейсу IEnumerable<T>, що дозволяє викликати їх через крапку у вигляді зручного ланцюжка запитів.

4. Приклад власного методу розширення для IEnumerable<T>
Прикладом є метод public static int TotalPages(this IEnumerable<Chapter> chapters) => chapters.Sum(c => c.PageCount);, оголошений у статичному класі. Його призначення — інкапсулювати бізнес-логіку підрахунку загальної кількості сторінок для будь-якої колекції розділів, що дозволяє лаконічно викликати його безпосередньо на списку через крапку (наприклад, book.Chapters.TotalPages()).
