Під час виконання лабораторної роботи №3 на тему «Життєвий цикл об’єкта та керування ресурсами» було досягнуто поставленої мети — поглиблено розуміння життєвого циклу об’єкта в C#, опановано особливості роботи з некерованими ресурсами, а також успішно реалізовано інтерфейс IDisposable та патерн Dispose у класі FileLogger. У ході практичних досліджень було детально проаналізовано відмінності між трьома сценаріями управління ресурсами. Перший сценарій із використанням оператора using показав себе як найбільш надійний та детермінований підхід, який гарантує автоматичний виклик Dispose() при виході з блоку коду навіть у разі виникнення винятків. Другий сценарій продемонстрував можливість явного виклику Dispose() вручну для негайного звільнення ресурсів. Третій сценарій підтвердив ефективність роботи деструктора та збирача сміття через GC.Collect(), показавши, що фіналізатор слугує страховим механізмом, а метод GC.SuppressFinalize(this) дозволяє уникнути повторного звільнення вже закритого ресурсу.
