Самостійна робота No5

• Тема: Приклади поліморфізму в .NET.
• Обсяг: 80 хв (2 академічні години)

Мета
Дослідити, як поліморфізм реалізований та використовується в стандартних бібліотеках .NET, а
також проаналізувати його переваги на конкретних прикладах.

**Висновок:** Поліморфізм у .NET дозволяє писати універсальний код, який працює з різними типами даних через єдину абстракцію. Перевизначення `ToString()` для `System.Object` дає змогу зберігати й коректно виводити різноманітні об'єкти в одній колекції `List<object>`. Реалізація `IEnumerable<T>` надає єдиний стандарт для обходу будь-яких власних структур даних через цикл `foreach`. Робота з базовим абстрактним класом `Stream` робить метод `ProcessStream` незалежним від конкретного джерела даних (`FileStream` чи `MemoryStream`), що гарантує гнучкість, повторне використання коду та легку розширюваність системи.
