Самостійна робота No7

• Тема: Узагальнений кеш Cache<TKey, TValue> із тестами.
• Обсяг: 80 хв (2 академічні години)

Мета
Розробити узагальнений клас кешу, який зберігає дані за ключем та має політику видалення
найстаріших елементів (FIFO - First In, First Out), а також написати юніт-тести для перевірки його
функціональності. Додатково можна реалізувати LRU як розширення базового рішення.

**Висновок:** Узагальнений клас `Cache<TKey, TValue>` успішно реалізує політику витіснення FIFO (First In, First Out) за допомогою словника `Dictionary` для швидкого пошуку за ключем та черги `Queue` для відстеження порядку додавання елементів. Написаний набір юніт-тестів у проєкті `IndependentWork7.Tests` повністю покриває ключові сценарії (додавання, отримання за ключем, перевірку наявності, підрахунок кількості елементів та поведінку при перевищенні заданої ємності з викиданням винятків), гарантуючи коректність та надійність розробленої системи.
